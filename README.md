# DV Compass

موقع مجاني بيجمع كل المعلومات والأدوات اللي محتاجها أي حد بيفكر في قرعة الهجرة العشوائية لأمريكا — **مش الفايزين بس**.
شغال بالكامل لواحد مكسبش ومش مقدّم: مفيش خانة رقم حالة ومفيش ميزة مقفولة.
مفيش اشتراكات، مفيش إعلانات، مفيش تسجيل دخول. كل بياناتك على جهازك انت بس.

---

## 📝 إزاي تحدّث معلومة (من غير ما تكون مبرمج)

المعلومات دي بتتغير، والموقع لازم يفضل صح. لو لقيت رقم قديم:

**١.** افتح فولدر `content` واختار الملف:

| المعلومة | الملف |
|---|---|
| الرسوم الرسمية | `content/fees.json` |
| خطوات الرحلة ومددها | `content/steps.json` |
| الأوراق المطلوبة | `content/documents.json` |
| بيانات مدينة (إيجار، مواصلات، الحاجة للعربية) | `content/metros/اسم-المدينة.json` |
| بيانات ولاية (ضرايب، رخصة، تأمين) | `content/states/الكود.json` |
| تطبيق شغل | `content/jobs/اسم-التطبيق.json` |
| مصطلح في القاموس | `content/glossary.json` |

**٢.** دوّر على الرقم وغيّره:

```json
{
  "value": 330,
  "status": "verified",
  "sources": [{ "label": "Department of State", "url": "https://travel.state.gov/..." }],
  "lastVerified": "2026-08-25"
}
```

**٣.** غيّر **تلات حاجات** مع بعض:
- `value` → الرقم الجديد
- `status` → شوف الجدول تحت
- `lastVerified` → تاريخ النهاردة بالشكل `YYYY-MM-DD`

### الـ`status` يبقى إيه؟

| لو انت… | حط | ولازم معاه |
|---|---|---|
| شفت الرقم بعينك على موقع رسمي | `"verified"` | لينك مباشر في `sources` |
| مش لاقي مصدر رسمي بس عندك تقدير معقول | `"estimated"` | `basis` (التقدير جه منين) و `verifyIn` (يتراجع كل قد إيه) |
| مش متأكد خالص | `"NEEDS_VERIFICATION"` | `"value": null` |

مثال لتقدير:

```json
{
  "value": 3,
  "status": "estimated",
  "sources": [],
  "lastVerified": "2026-08-25",
  "basis": {
    "ar": "تقدير من معرفة عامة بشبكة المواصلات — مش من قياس",
    "en": "Estimate from general knowledge of the transit network, not measured"
  },
  "verifyIn": "1-year"
}
```

> **فيه حالة رابعة `judgment`** لحقلين بس (`arabCommunity` و `gigDemand`). دي أحكام شخصية مش أرقام، وبتتعرض للمستخدم كوصف — "جالية عربية كبيرة" مش "٤ من ٥". لو مش شغال عليهم تحديدًا، متستخدمهاش.

**٤.** احفظ واعمل commit. الموقع هينزل لوحده على Vercel.

> ⚠️ لو مش متأكد من رقم، حط `"value": null` و `"status": "NEEDS_VERIFICATION"`. الموقع هيعرض "محتاج تأكيد" مكانه. **ده أحسن ألف مرة من رقم مغلوط** — في ناس بتاخد قرارات بفلوسها على أساس الأرقام دي.

## 🔍 إيه اللي محتاج مراجعة دلوقتي؟

```bash
npm run verify-content
```

بيتأكد إن كل ملفات المحتوى سليمة، وبيعيد كتابة `TODO-VERIFY.md` كله — فيه الأولويات، والحقول اللي عدّى ميعاد مراجعتها، والإنجليزي الناقص.

**`TODO-VERIFY.md` بيتولّد تلقائي — متعدلوش بإيدك.**

ولو حاجة في المحتوى مكسورة، `npm run build` بيقف ويقولك اسم الملف والحقل بالظبط.
