# الأسعار — ملف واحد تكتب فيه بنفسك

كل أسعار الخمسين مدينة في ملف واحد: **`data/الأسعار.csv`**.

افتحه بإكسل أو Google Sheets، غيّر اللي عايزه، احفظه، وبعدين:

```bash
npm run prices
```

وده بيكتب اللي كتبته في `content/metros/` — الخمسين ملف — من غير ما تفتح ولا واحد منهم.

عايز تتأكد قبل ما يكتب حاجة؟

```bash
npm run prices -- --check
```

## ليه كل سعر تلات خانات

```
أوضة_من      أوضة_الأرجح      أوضة_لـ
  1,325         1,580          1,955
```

**الرقم الواحد بيوحي بدقة مش موجودة.** الأوضة في نيويورك وسيطها ‎$1,580‎،
بس نص الإعلانات فعلًا بين ‎$1,325‎ و‎$1,955‎ — اللي بيخطط بالوسيط لوحده
ممكن يتصدم بفرق ٦٠٠ دولار في الشهر.

- **الأرجح** — ده اللي الخطة بتحسب بيه. لو سيبته فاضي، الحقل بيبقى
  "محتاج تأكيد" والموقع بيقول للمستخدم إننا مش عارفين، مش بيفترض صفر.
- **من / لـ** — بيظهروا للمستخدم كـ"أغلب الأسعار بين كذا وكذا".
  اختياريين، بس لما تحطهم الصورة بتبقى أصدق بكتير.

## الأعمدة

| العمود | يعني إيه |
|---|---|
| `المدينة` | الاسم البرمجي — **متغيّرهوش**، ده اللي بيربط الصف بملف المدينة |
| `الاسم` | للقراية بس، الاستيراد بيتجاهله |
| `أوضة_*` | أوضة في شقة مشتركة — ده اللي الفرد الرايح لوحده بيدفعه |
| `شقة_غرفة_*` · `شقة_غرفتين_*` | للعيلة الداخلة مع بعض |
| `فواتير_الشقة_داخلة` | `نعم` لو سعر الشقة شامل المياه والكهربا. لو `نعم`، سيب عمود `الفواتير` فاضي — وإلا الفواتير هتتحسب مرتين والسكريبت هيوقفك |
| `الفواتير` · `تأمين_العربية` · `اشتراك_المواصلات` · `أكل_للفرد` | رقم واحد لكل واحد فيهم |
| `مصدر_الأوضة` · `مصدر_الشقق` · `مصدر_باقي_الأرقام` | **إجباري.** كل رقم لازم يقول جه منين — ده اللي بيظهر للمستخدم تحت الرقم |
| `مرجع_سوق_الشقق_Zillow` | مرجع بس، الاستيراد بيتجاهله. مستوى السوق المرصود للشقق في المدينة، يساعدك وانت بتملا خانات الشقق |

## الأرقام اللي في الملف دلوقتي

- **الأوض** — ٣٤ مدينة من وسيط إعلانات فعلية على SpareRoom (٣٢ لـ٢٠٤ إعلان
  للمدينة)، والنطاق هو الربع الأدنى والربع الأعلى الحقيقيين. و١٦ مدينة
  مفيهاش تغطية إعلانات، أرقامها **متوقّعة من معادلة** ومكتوب كده في مصدرها.
- **الشقق** — الخمسين مدينة من HUD FY2026 الرسمي. خانات `من`/`لـ` سايبة
  فاضية **بقصد**: عندنا توزيع حقيقي للأوض مش للشقق، واختراع نطاق ليها
  هيبقى نفس الغلطة اللي الموقع كله بيحاربها. املاها لما تبحث.
- **الأكل** — رقم USDA، واحد لكل أمريكا لأن USDA مبتفرقش بين المدن.

الداتا الخام وطريقة اشتقاق كل رقم في `data/rent-data-2026-08-26.json`.
